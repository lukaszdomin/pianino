# Świecące Klawisze

Aplikacja do nauki gry na keyboardzie **The ONE COLOR**: wybierasz utwór, a keyboard podświetla klawisze, które trzeba nacisnąć.

**Otwórz na iPadzie w aplikacji Web MIDI Browser:** https://lukaszdomin.github.io/pianino/
